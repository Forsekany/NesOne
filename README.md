# NesOne

A lightweight NES emulator for Android, written in pure Java with **zero external libraries**.

NesOne has a clean Material-style interface, on-screen touch controls, audio, battery saves, and a 30/60 FPS mode.

## Download

Get the latest APK from the [Releases](../../releases) page.

**Requires Android 5.0 (API 21) or newer.**

## Features

- NES emulation: CPU, PPU and APU written from scratch
- On-screen touch controls with haptic feedback
- Battery-backed save support (stored per game)
- 30 / 60 FPS mode and optional FPS counter
- Light and dark theme
- Smooth animated UI
- No dependencies

## Supported mappers

| Mapper | Board |
|--------|-------|
| 0 | NROM |
| 1 | MMC1 |
| 2 | UxROM |
| 3 | CNROM |
| 4 | MMC3 |
| 7 | AxROM |
| 11 | Color Dreams |
| 66 | GxROM |
| 71 | Camerica |

## How to use

1. Download and install the APK (allow "install unknown apps" if Android asks).
2. Open NesOne and pick a `.nes` ROM file from your device.
3. Play!

NesOne does not include any games.

## Reporting bugs

If a game doesn't run, open an issue with the game name, its mapper number, and your Android version.
